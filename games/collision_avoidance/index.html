Instructions:

See how many satellites you can get in orbit while avoiding collisions!
Add a new orbital plane by dragging the sliders below. The game propagates rolling 24 hour windows and estimates the minimum distance between satellites across the constellation (shown in the CLEARANCE PROFILE and PAIRWISE CLEARANCE visualizations). If any two satellites pass within 10 km, the plane is rejected.
Limitations: single altitude (550 km); simple secular J2 propagation model; etc.
